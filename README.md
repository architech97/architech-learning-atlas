# ArchiTECH Learning Atlas

A source-led learning website connecting architectural construction and software engineering.

## Explore

- 15 landmark buildings across five architectural practices
- 202 evidence records with source URLs, page/sheet locators, inspection methods and limitations
- Full original architectural research and downloadable CSV/JSON evidence
- 18 selected software-learning tracks and seven initial source-backed lesson briefs
- Search, architect filters, keyboard-accessible detail dialogs and responsive layouts

## Research scope

Snapshot: 20 October 2026. Original analysis is provided for education and precedent study. Published source documents remain with their respective owners. No complete coordinated construction set, editable native BIM model, engineering certification or manufacturing approval is claimed. Software study is a first research pass, not mastery of all roadmap topics.

## Implementation

Static HTML, CSS and JavaScript; no package dependencies, external fonts, tracking, authentication or client data. `index.html` includes the research data and reading views. `evidence.csv`, `evidence.json`, `architecture-research.md` and `software-learning.md` provide reusable exports. GitHub Pages serves the root of `main`.

## Rights

Third-party materials are linked rather than republished. Source attribution and limitations accompany each evidence record. Original conceptual diagrams are not project construction drawings.
